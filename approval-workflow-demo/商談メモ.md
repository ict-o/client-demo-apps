# 商談メモ｜承認ワークフロー・電子契約管理システム

商談でこのデモを見せながら話すための説明メモです（社内用・概要レベル）。
デモURL: https://ict-o.github.io/client-demo-apps/approval-workflow-demo/

---

## 1. 一言でいうと

**「紙とハンコの承認 → 契約締結 → 契約書の保管・管理」を、1つのシステムで最後まで完結させる仕組み**のデモです。

ワークフローツール・電子契約サービス・契約書管理サービスを別々に契約して繋ぐのではなく、
申請から締結・保管までが同じ画面の中で繋がっている、という点が一番の見どころです。

## 2. 想定しているお客様の課題

- 月100〜150件の稟議・捺印申請を紙で回していて、**今どこで止まっているか分からない**
- 承認者が出張・休暇で不在だと、**書類がその人の机で止まる**
- 契約書がキャビネットやファイルサーバに散在し、**更新期限を見落とす**
- 契約金額を会計システムへ**手入力で転記**している

→ デモの管理ダッシュボードで「承認待ち」「3日以上滞留」「更新期限60日以内」が数字で出るので、
　この課題感の説明にそのまま使えます。

## 3. 見せ方（所要5分）

**画面右上の「操作ガイド（ツアー）」ボタンから、全14ステップのガイド付きツアーが起動します。**
初回は画面を開いた時点で案内ダイアログが出るので、そのまま「開始」でOKです。
ツアーが該当画面へ自動で移動し、見てほしい箇所をハイライトするので、**商談中はツアーに沿って進めるのが確実**です。

自分で操作しながら説明する場合の流れ:

| 順 | 画面 | 話すこと |
|----|------|----------|
| 1 | 管理ダッシュボード | 滞留・署名待ち・更新期限が1画面で見える |
| 2 | 社内ワークフロー（申請一覧 → 詳細） | 誰の手元で止まっているかが分かる。承認ルートは金額・契約種別から自動判定 |
| 3 | 代理承認 | 右上の「利用者」を切り替えて代理承認を実演（不在でも止まらない） |
| 4 | 電子契約の送信準備 | **書類上をクリックして署名欄を配置**する操作は反応が良い |
| 5 | 相手先の署名画面 | 受け取った側の画面（メール → アクセスコード → 署名）も実演できる |
| 6 | 契約台帳 | 締結した契約が自動で登録され、期限・相手先・物件で検索できる |
| 7 | 紙契約書取込（OCR・AI抽出） | 紙で届いた契約書はOCRで読み取り、AIが項目抽出＋自動振り分け |
| 8 | 会計システム連携 | 会計システムへの連携と、連携失敗時の再連携まで見せられる |

時間がないときは **1 → 3 → 4 → 6** の4画面だけでも話は通ります。

## 3-2. 画面名は見積書の機能項目に合わせてあります

メニューの画面名は、お見積りの機能項目名と対応させています。
商談中に「この見積項目はこの画面です」と、見積書と画面を突き合わせて説明できます。

| 画面（メニュー名） | 対応する見積項目 |
|------|------|
| 管理ダッシュボード | 管理ダッシュボード・集計機能（フェーズ3） |
| 社内ワークフロー | 社内ワークフロー機能（フェーズ1） |
| 電子契約 | 電子契約基本機能（フェーズ1）／電子契約拡張機能・監査ログ・証跡（フェーズ2） |
| 契約台帳 | 契約台帳・基本検索、紙／電子契約の一元管理（フェーズ1）／高度な全文検索（フェーズ2）／契約更新・期限管理・アラート強化（フェーズ3） |
| 紙契約書取込 | 紙契約書のPDF登録・ドキュメント管理（フェーズ1）／OCR読み取り・AI自動抽出・自動振り分け（フェーズ2） |
| 会計システム連携 | 会計システム連携（フェーズ1）／追加外部システム連携・運用改善（フェーズ3） |
| 承認ルート設定 | 内容に応じた承認ルート設定＋多段階承認（フェーズ1）／ワークフロー追加・運用ルール拡張（フェーズ3） |
| 操作ガイド | テスト・導入・操作説明（フェーズ1） |

同じ対応表は、デモ画面内の「操作ガイド」にも表示されます。

**このデモに画面がない見積項目**: 認証・ログイン／ユーザー・組織・権限管理（フェーズ1）。
フェーズ1範囲に絞った `approval-workflow-phase1-demo` に「利用者・権限管理」画面があるので、必要ならそちらを併せて見せてください。
過去契約書・既存データ移行（フェーズ3）は画面を伴わない作業のため、デモには含みません。

## 4. 強調したいポイント（3つ）

1. **不在でも止まらない** — 代理承認を事前に設定でき、履歴には「代理承認」として残る
2. **電子契約が外部サービス任せではない** — 署名欄の配置・本人確認・期限管理・リマインド・監査ログ・締結証明まで自前で完結
3. **締結して終わりではない** — 締結した契約が自動で契約台帳に載り、更新期限のアラートと会計連携まで繋がる

## 5. 外部連携の範囲（聞かれやすいので先に言う）

**外部システムと接続するのは会計システムのみ。** それ以外はすべてシステム内で完結します。
会計側へ送るのは契約金額・賃料・支払期間・相手先・契約種別で、**契約書本文と署名情報は送りません。**
デモの「会計システム連携」画面に、機能ごとの区分（外部連携／内部完結）の一覧を用意してあります。

## 6. よくある質問と答え方

| 質問 | 答え方 |
|------|--------|
| 相手先が電子契約に対応していない場合は？ | 承認完了後に締結方法を選べます。「紙で締結する（捺印手配）」を選ぶと、捺印依頼 → 原本スキャン取込に分岐します（デモで実演可） |
| 本当に締結したと言えるのか | 誰がいつどこから開封・署名したかの監査ログと、書類のハッシュ値付きの合意締結証明書を発行します |
| 承認ルートは自社の規程に合わせられるか | 金額・申請種別・契約種別の条件で段階を組み立てる方式です。「承認ルート設定」画面で条件一覧とシミュレーションを見せられます |
| AI抽出はどのくらい当たるのか | 項目ごとに抽出確度を表示し、確認画面で人が直してから登録する運用です（全自動にはしない） |
| スマホでも使えるか | 画面はレスポンシブ対応。商談中にその場でスマホから開いてもらえます |

## 7. デモを見せるときの注意

- **表示されている企業名・担当者名・物件名・金額はすべて架空のサンプル**です。実在の企業・案件ではありません。
- リロードすると初期状態に戻ります（データはブラウザのメモリ内だけで保持）。
  **操作を戻したいときはリロードでリセット**できる、と覚えておくと安心です。
- デモ一覧ページにはパスワードがかかっています。デモURLを直接共有すれば個別に開けます。
- あくまで提案用のモックです。実装範囲・スケジュール・費用は別途お見積りになる旨を添えてください。
